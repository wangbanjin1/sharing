# Introduction

## From "remember more" to "remember well" to "remember accountably"

Transformer-based agents are bounded by finite context and KV-cache limits. The dominant responses (larger context windows, retrieval augmentation, and summarization) treat memory as *storage*: text to be replayed or searched. But a lifelong agent does not need its full history; it needs decision-relevant *state*: commitments, learned rules, reusable procedures. This state-not-storage view, the idea that long-horizon intelligence is a state-management problem rather than a context-length problem, motivates a cognitive state plane that governs the formation, evolution, retrieval, and decay of episodic, semantic, and procedural state under bounded context [@stateplane]. Within that view, converting raw experience into durable state is the *consolidation* problem, and it is where long-horizon intelligence is won or lost [@stateplane; @episodicgap; @compspectrum]. This program studies that consolidation step in isolation.

This paper reports a four-phase program on consolidation. Its arc is deliberate, and the order matters:

1.  **Remember more** was never the goal; we begin (Phase 1) by asking where experience should even be *segmented* into episodes, since that determines what can be consolidated at all.

2.  **Remember well** (Phases 2--3): learn *when* and *to what level* to abstract, and, because the field had no way to score this, build the instrument that measures consolidation *decision quality* against a computable optimum.

3.  **Remember accountably** (Phase 4): make the act of abstraction itself *governed*, that is, poison-resistant, reversible, and auditable, because an agent that distills a false rule will act on it and defend it.

## The throughline: epistemics

The single most useful thing we can report is a pattern that only became visible at the end. Each phase set out to *solve* something; each phase's lasting contribution was instead a way to *know*: how to know you are not self-leaking (Phase 1), how to know why a learned forgetting gate fails (Phase 2), how to know whether *any* agent's consolidation is good (Phase 3), and how to *audit, reverse, and constrain* what an agent has decided to believe (Phase 4). In a field where "we solved memory" claims age quickly, "here is a rigorous way to know whether memory is solved" is the durable contribution. We organize the paper around this throughline.

## Contributions

1.  **An anti-leakage protocol for learned memory experiments** (Phase 1): provenance, probe, and count-matched gates that prevent a learner from covertly reading the answer key. This discipline underwrites every later result.

2.  **A learned promotion-and-level policy** (Phase 2) with a verified improvement and compression, *and* two rigorously characterized failure mechanisms (degenerate forgetting; $\lambda$--prevalence coupling) reported as first-class findings.

3.  **ConsolidationBench** (Phase 3): to our knowledge the first benchmark scoring consolidation *decisions* against an oracle-by-construction, on three non-circular axes, with an honest leaderboard.

4.  **Governed consolidation** (Phase 4): a policy-agnostic mechanism wrapping the consolidation decision in poison-resistance, reversibility, and auditability. It carries an *insurance property*: governance is statistically distinct from the quality metric, so the contribution does not depend on that metric's contested external validity.

5.  **A reusable methodology of adversarial self-critique**: at each phase a separate verification pass attacked the claims, caught overclaims, and forced hedges; we report the resulting ledgers, not just the survivors.

#### A note on disclosure (Section [7](#sec:repro){reference-type="ref" reference="sec:repro"}). {#a-note-on-disclosure-section-secrepro.}

This work has a production lineage. Certain mechanism internals, specific gate thresholds, the instability and detail-grounding signal definitions, and certain benchmark-generator parameters are described *functionally* here and held under controlled release. Every reported number nonetheless traces to a persisted artifact that reproduces bit-exactly; the withheld items are implementation constants, not the findings.

# Phase 1, Where Does a Memory Begin? {#sec:p1}

## Problem

Before experience can be consolidated, a continuous stream of agent transitions $(s,a,r,s')$ must be segmented into episodes. Prior systems either segment heuristically (fixed-interval; Bayesian surprise over token streams [@emllm]; topic coherence) or learn consolidation on *pre-given* boundaries [@genagents; @hipporag]. None simultaneously (i) reads agent traces, (ii) learns boundaries without label supervision, and (iii) optimizes them by downstream task utility. This is the gap Phase 1 targets, grounded in the cognitive-science account of event segmentation [@zacks; @tulving].

## Method and result (honest near-miss)

We train a boundary detector ([BoundaryLearner]{.smallcaps}) on procedurally generated traces with planted ground-truth boundaries, optimized end-to-end by downstream reward with *no* boundary labels. A pre-registered success criterion required held-out oracle correlation $>0.70$, $>10\%$ task-success gain over fixed-interval, and beating Bayesian-surprise and topic-coherence baselines.

  Bayesian Surprise         0.895         0.315          0.705          0.554

The result is a near-miss, reported as a failure.

## The lasting contribution: not the detector, the discipline

Phase 1's durable output is the **three-gate anti-leakage protocol**, which we state precisely because every later phase re-applies it:

- **Provenance gate.** The observable feature surface is mechanically checked to contain no generator-internal field; a learner cannot read what it is supposed to infer.

- **Probe gate.** A linear probe trained to predict the latent answer from each individual observable feature must not exceed chance by more than a small margin; this rules out a single feature silently encoding the label.

- **Count-matched gate.** Controls hold confounds (cluster counts, budget pressure) fixed across conditions, so an apparent improvement cannot be an artifact of unequal exposure.

This protocol is what makes every subsequent "the learner improved" claim trustworthy, by ruling out the most common silent failure, a model that scores well by reading the answer it was supposed to infer. Phase 1 thus establishes the program's first epistemic tool: *a way to know you are not cheating.*

# Phase 2, When, and to What Level, to Abstract {#sec:p2}

## A verified gain, and a precisely characterized failure

Phase 2 learns a policy that selects, per experience cluster, *when* to promote and *to which level* (keep, summarize, extract skill, distill rule, forget) under a hard token budget. Adversarially verified on ten fresh held-out seeds and reproduced bit-exactly from disk, the policy achieves a **$+22.7\%$ relative task-success improvement** over the best non-learned baseline on the medium configuration (paired CI $[+1.89,+11.34]$ pp, excluding zero), with **$7.17\times$ memory compression** (CI entirely above the pre-registered $5\times$ bar).

The full pre-registered criterion is nonetheless *not met*, for a reason we characterize quantitatively rather than excuse. Forgetting precision sits at chance ($0.319$ vs. a junk base rate of $0.333$); the policy uses `FORGET` as a budget-pressure release valve, destroying $74\%$ of load-bearing clusters at least once, and $75\%$ of a hard-configuration transfer regression ($-15.0$ pp, CI excluding zero) traces to a single causal chain: budget-pressure forget $\rightarrow$ premature re-promotion $\rightarrow$ wrong artifact $\rightarrow$ transfer poisoning. The diagnosis is the contribution: the saturation-conditioned "when" was learned for *promotion* but not for *forgetting*.

This precision matters because the benchmark cannot be won without it: raw experience mass exceeds the reference budget by $7.3\times$/$9.4\times$, so a policy that stores everything necessarily loses load-bearing evidence to forced eviction. The level matters too: a recurring parametric sub-task warrants a skill ($50$--$500\times$ compression), a stable invariant a rule, and a one-off neither, applying the wrong transform is not merely inefficient but actively destructive, since a falsely distilled rule *overrides* the correct raw evidence it replaced. This is the "missing diagonal" of adaptive cross-level compression [@compspectrum], and it is what the Phase-2 policy learns for promotion and fails to learn for forgetting.

## Targeting forgetting, and a second mechanistic finding

A follow-on design adds agent-observable forgetting-evidence features and a hindsight regret credit signal trained without oracle labels. Forgetting precision rises from chance to **$0.932$ (hard) / $0.833$ (medium)**, both CIs excluding the junk base rate. But the gate becomes near-inactive, about $0.61$ forgets per seed versus ${\sim}30$ before, so overall success regresses. The root cause is a new, named failure mode: **$\lambda$--prevalence coupling**, a hindsight-regret hyperparameter tuned at one junk prevalence ($0.593$) collapses the gate when evaluated at another ($0.388$). This is a general distribution-shift hazard for regret-based forgetting signals, reported with a concrete fix pathway. Phase 2's epistemic tool: *a way to know why a plausible mechanism fails.*

# Phase 3, Measuring Consolidation Decision Quality {#sec:p3}

## The gap: everyone scores accuracy, nobody scores the decision

Contemporary agent-memory benchmarks score *downstream task accuracy* [@longmemeval; @amabench; @memoryagentbench; @memoryarena; @beam; @locomo], which confounds three independent factors: base-model capability, retrieval quality, and consolidation-decision quality. The Experience Compression Spectrum [@compspectrum] names the four-level hierarchy (trace, summary, skill, rule) and a "missing diagonal" of adaptive cross-level compression, but ships no benchmark. ConsolidationBench fills exactly this slot.

## ConsolidationBench: an oracle-by-construction

ConsolidationBench procedurally generates experience streams in which the ground-truth consolidation value of every cluster is known *by construction*, making the optimal promotion policy *exactly computable*. The stream contains latent cluster types, including near-rule *poison decoys* that look stable then break, each encoding a consolidation challenge whose optimal action is known.^$\dagger$^ Policies observe only a whitelisted feature surface (the Phase-1 anti-leakage gates are re-applied); the oracle and latent types are never observable.

The latent cluster types span the consolidation challenge space: recurring parametric sub-tasks (which warrant skills), stable invariants (rules), one-off distractors (forget), and the near-rule poison decoys central to Phase 4. A *hard budget* makes the benchmark unwinnable by hoarding: raw experience mass runs $7.3\times$/$9.4\times$ over the reference budget, so forced eviction destroys load-bearing evidence unless the policy compresses intelligently. Crucially, a *headroom gate* verifies, before any learner is trained, that the oracle meaningfully outscores the best non-learned baseline, ruling out a benchmark that cannot discriminate. The Phase-1 anti-leakage gates are re-applied so that no policy can covertly read the latent type.

Three *non-circular* axes score each policy as a fraction of the computable optimum: **Retention** (oracle-normalized task success), **Compression** (token-mass ratio under a matched budget), and **Reuse** (transfer to novel composite tasks). The headline metric is the *Consolidation Quality Score*, $\textsc{CQS}{} = \sqrt{\text{retention\_norm}\times(\text{reuse\_credit}+\epsilon)}/\sqrt{1+\epsilon}$ with $\epsilon=0.05$, oracle-normalized in $[0,1]$ (the graded-reuse form; see Section [5.4](#sec:validity){reference-type="ref" reference="sec:validity"}). The geometric mean rewards *both* retention and generalization while the small floor prevents the reuse term from acting as an all-or-nothing gate, so a policy with real retention is graded rather than zeroed when it fails to generalize.

#### Two forms, labeled.

Phases 3 and 4 were scored, and their adversarial audits run, under the original multiplicative form $\textsc{CQS}\ensuremath{_0}{} = \text{retention\_norm}\times\text{reuse\_credit}$, before the redesign described in Section [5.4](#sec:validity){reference-type="ref" reference="sec:validity"}. We report [CQS]{.smallcaps}$_0$ wherever a Phase-3 or Phase-4 number was computed under it (Tables [1](#tab:leaderboard){reference-type="ref" reference="tab:leaderboard"} and [2](#tab:gov){reference-type="ref" reference="tab:gov"}, and the correlations of Section [5.3](#sec:insurance){reference-type="ref" reference="sec:insurance"}), and the graded [CQS]{.smallcaps} wherever the redesign applies (the leaderboard's final column and the external-validity study). Both are oracle-normalized in $[0,1]$ and share the same retention and reuse inputs; they differ only in how the reuse term aggregates.

## The leaderboard finding

Across ten policies (no-consolidation, fixed-level, heuristic, learned, and literature-faithful Mem0-style [@mem0; @zep] and SimpleMem-style [@simplemem] designs), **no method closes the oracle gap** (Table [1](#tab:leaderboard){reference-type="ref" reference="tab:leaderboard"}). Eight of ten score $\textsc{CQS}\ensuremath{_0}{}=0$ because they achieve zero composite-task transfer; under the graded form they are separated by retention alone, and the transfer column is still zero. Critically, the literature-faithful retrieval systems achieve *solid retention* (oracle-normalized $0.53$ / $0.49$) yet *zero transfer*: on the axis that distinguishes a filing cabinet from a memory, the dominant production designs score nothing. This is invisible to accuracy benchmarks and surfaced only by scoring the decision against a known optimum.

#### Non-circularity.

The three axes are empirically distinct: the maximum pairwise correlation across all axis pairs is $|r| = 0.59$, and compression vs. retention is $0.17$ (medium) / $0.23$ (hard), all far below the $0.9$ redundancy threshold. [CQS]{.smallcaps} is therefore a genuine three-dimensional measurement, not a single quantity in disguise. Phase 3's epistemic tool: *a way to know whether any agent's consolidation is good.*

# Phase 4, Governing the Consolidation Decision {#sec:p4}

## The new question: who guards the abstraction?

Consolidation is the highest-risk memory operation: a distilled rule *overrides* downstream reasoning, so a wrong abstraction silently corrupts every decision that retrieves it. Three failure modes follow: **poison** (a false rule distilled from a pattern that broke), **irreversibility** (no undo once the rule is in), and **opacity** (no record of why a belief exists). The 2026 memory-governance literature governs *storage and sharing* (provenance, scoped retrieval, cross-tenant isolation) [@memarchitect; @memclaw; @ssgm; @memsec], but it does not govern the consolidation *decision* itself. That gap is the contribution's target.

## Governed consolidation

We wrap the consolidation decision in three guarantees plus a quality gate, all measured on ConsolidationBench:

- **G1 Poison-resistance.** A gate refuses to distill a durable rule when an *instability signal* indicates the pattern is breaking.^$\dagger$^ Measured: it admits **zero** false rules from the planted poison decoys (both configurations).

- **G2 Reversibility.** When post-promotion evidence contradicts a distilled rule, a *rollback* removes the false artifact and restores the source experiences.^$\dagger$^ Measured: on a temporal-contradiction variant, rollback fires on $5/5$ seeds and a with/without-rollback contrast shows task success recovering from $0.0$ to $1.0$.

- **G3 Auditability.** Every promotion writes a governance-ledger record (provenance, decision rationale, instability score, reversibility, rollback status). Measured: complete records for $100\%$ of promotions; ledger queries ("why does rule $R$ exist? what did it influence? show its rollback") are answerable.

- **G4 Quality gate.** Governance credit is granted only if consolidation quality is not degraded. This is *mandatory*: without it, a policy that never abstracts trivially "passes" G1--G3 by inaction.

The headline composite binds the governance score to G4 as a conjunction; the governed policy is the only evaluated policy satisfying both (Table [2](#tab:gov){reference-type="ref" reference="tab:gov"}).

## The insurance property (why this survives a hostile reviewer) {#sec:insurance}

The governance results are measured on a synthetic benchmark whose quality metric does *not* predict external transfer accuracy (Section [5.4](#sec:validity){reference-type="ref" reference="sec:validity"}). A natural objection, now sharpened by that negative: if the quality score fails as an external predictor, why trust governance measured against it? An earlier framing of our answer rested on a correlation threshold (all twenty governance-vs-quality pairs below $|r| = 0.9$, maximum $0.87$); a hostile reviewer would rightly note that $0.87$ is substantial correlation and the threshold lenient. The distinctness claim does not rest on it. Three treatments of the same data (descriptive; the ten rows are five policies by two configurations, not independent; all computed under [CQS]{.smallcaps}$_0$, the form in use when Phase 4 ran): first, the maximum pair is one gate against one axis, structurally driven by a single policy anchoring both ends, while the headline pair, aggregate governance versus [CQS]{.smallcaps}$_0$, is $r = 0.65$, so [CQS]{.smallcaps}$_0$ explains under half of governance variance ($r^2 = 0.43$); second, the partial correlation controlling for task success is $r = 0.27$, meaning the apparent relationship is mostly mediated by shared task quality; third, and decisively, policies with *identical* [CQS]{.smallcaps}$_0$ differ threefold in governance score, and $56\%$ of governance-score variance lies *within* [CQS]{.smallcaps}$_0$-matched groups, a majority of what governance measures being invisible to the quality metric by construction. This dissociation matters because the three guarantees rest on quantities that do not depend on [CQS]{.smallcaps} at all: G1 is a ground-truth false-rule count, G2 a behavioral task-success measurement, G3 a structural ledger-completeness count. **The governance contribution stands even if the quality metric's validity is undermined further**, this is the paper's insurance property.

## External validity: a metric redesign, and a resolved negative {#sec:validity}

We tested whether [CQS]{.smallcaps} predicts real transfer accuracy, and the honest answer is that it does not. Arriving at that answer required first repairing the metric, then running a study large enough to settle the question. We report the full arc because each step is a contribution in its own right.

**Over-credit diagnosis.** An early transfer-focused study exposed a flaw in the original [CQS]{.smallcaps}: it gave *phantom transfer credit* to aggressive summarizers. One baseline passed composite tasks while having discarded the very specifics those tasks require ($70\%$ of oracle composite success on only $14\%$ of oracle detail retention). A *detail-grounding factor* that makes transfer credit proportional to preserved instance-specific information corrects this;^$\dagger$^ applied uniformly it *lowers* our own best policy's score, which we report rather than hide.

**The structural ceiling, and its redesign.** A stronger validity test was blocked by the metric's own form. The original $\textsc{CQS}\ensuremath{_0}{} = \text{retention\_norm}\times
\text{reuse\_credit}$ multiplies retention by a reuse credit that is zero for any policy that never lands a composite-transfer task, so the reuse term acted as a near-binary gate: it annihilated policies with healthy retention (a Mem0-style policy at $0.55$ normalized retention scored zero) while a *random* policy that occasionally landed a transfer task scored above them. Fifteen of twenty policy-configuration rows collapsed to exactly zero, making a rank-correlation study over eight or more policies impossible by construction. We redesigned the reuse aggregation, pre-registering the acceptance bars on oracle-construction grounds rather than tuning against real-data outcomes. Of four candidate aggregations, the geometric mean with an $\epsilon = 0.05$ floor, $\textsc{CQS}{}=\sqrt{\text{retention\_norm}\times(\text{reuse\_credit}+\epsilon)}/\sqrt{1+\epsilon}$, was the only form to satisfy every bar simultaneously: collapse drops from fifteen of twenty rows to *zero*; the metric stays discriminant from retention ($\rho(\textsc{CQS}{},\text{retention}){=}0.88$, below the $0.9$ ceiling, so reuse is not dead weight); non-circularity is preserved ($|\text{corr}(\text{compression},\text{retention})|{=}0.20$); and it still tracks transfer among generalizing policies ($\rho(\textsc{CQS}{},\text{transfer}){=}0.90$). An additive aggregation was rejected for collapsing [CQS]{.smallcaps} onto retention ($\rho{=}0.98$). This is a positive methodological result: the headline metric now resolves the full policy space rather than tying most of it at zero.

**The resolved negative.** With the metric resolving a twelve-policy panel (twelve distinct scores, zero collapse), we ran the study the ceiling had previously blocked: two benchmarks (LoCoMo multi-hop and 2WikiMultiHopQA), $2{,}532$ real answer cells generated by genuine per-policy consolidation and answering, with a single-hop control. The result is a clean **NOT-SUPPORTED**: pooled Spearman $\rho = -0.24$ ($n{=}12$; permutation $p = 0.45$; bootstrap $95\%$ CI $[-0.79, +0.49]$, spanning zero), replicated as $\rho =
+0.03$ on LoCoMo and $\rho = -0.30$ on 2Wiki, with no leave-one-out exclusion turning it positive. The single-hop guard inverts (control $\rho = +0.32 >$ multi-hop $-0.24$), and per-axis disaggregation shows all three axes fail individually, so this is a framework misalignment rather than one bad axis. The mechanism is legible in the data: a `no_consolidation` baseline (raw documents, no processing) achieves the second-highest 2Wiki accuracy despite the lowest [CQS]{.smallcaps}, because real multi-hop QA on that corpus is solved by raw-fact retrieval, whereas [CQS]{.smallcaps}'s reuse axis credits skill- and rule-artifact transfer. The two constructs simply do not coincide.

**What we therefore claim.** [CQS]{.smallcaps} is a resolution-valid, discriminant, non-circular, oracle-normalized measure of the consolidation *decision*. It is *not* a validated predictor of downstream answer quality, and we do not claim it as one; a high [CQS]{.smallcaps} (including our own best policy's benchmark leadership) certifies structural consolidation quality against the oracle, not superior real-task accuracy. Recalibrating [CQS]{.smallcaps} into a transfer predictor would require redefining its composite-task axis to match how real multi-hop questions are answered, which we leave as future work.

## Adversarial self-critique

A dedicated verification pass attacked the Phase-4 claim set: $17$ claims, **zero surviving overclaims**, three required hedges, (i) governance must bind G4 (a "promote-nothing" adversary games the governance score by inaction); (ii) G2 is demonstrated on a purpose-built contradiction variant that triggers rollback in all $16$ tested parameter settings, i.e. a construction stronger than the main benchmark's break pattern; (iii) every [CQS]{.smallcaps}-dependent claim is labeled partial-validity. We report the ledger, not just the survivors. Phase 4's epistemic tool: *a way to audit, reverse, and constrain what an agent decides to believe.*

## The adversarial-verification methodology, across phases

A distinguishing feature of this program is that every phase ran a *separate* adversarial-verification stage that attacked its own claims before publication. We report the resulting ledgers rather than only the survivors (Table [3](#tab:adv){reference-type="ref" reference="tab:adv"}). This is not incidental: the anti-leakage gates (Phase 1) were re-applied in every later phase, the headroom gate verified benchmark sensitivity before any learner was trained, and the Phase-4 audit caught the gameable-governance exploit and forced the mandatory G4 binding. Honest negatives are first-class outputs here.

# Related Work

**Memory benchmarks.** Task-accuracy benchmarks [@longmemeval; @amabench; @memoryagentbench; @memoryarena; @beam; @locomo] and skill-generation benchmarks [@skillgenbench] measure end-to-end outcomes; ConsolidationBench isolates the consolidation *decision* against an oracle. **Memory architectures.** Mem0/Zep [@mem0; @zep], SimpleMem [@simplemem], and recent designs [@recmem; @amem; @timem; @atommem; @memskill] are consolidation *policies*; governed consolidation is a policy-agnostic governance *wrapper*. **Memory governance.** The field has recently converged on governance of agent memory as a named problem, which sharpens rather than threatens this contribution. SSGM [@ssgm] is a theoretical architecture (write-validation gating, reversible reconciliation via a dual-track memory) with no empirical measurements; the Verifiable Memory Governance predicates of [@memsec] formalize rollbackability, verified forgetting, and provenance visibility as evaluable desiderata, while that survey itself marks verified forgetting "no existing literature," rollbackability "largely absent," and finds no benchmark covering the full memory lifecycle. MemEvoBench [@memevobench], the closest implemented benchmark, scores LLM-judged downstream attack success over a hardcoded memory-append rule, with no rollback concept. We do not claim to have introduced the idea of governing or reversing agent memory; the claim is narrower and verifiable: the first oracle-by-construction *measurement* of governance at the consolidation decision, our G2 instantiating rollbackability plus verified forgetting (exact-state rollback including derivative cleanup) and G3 instantiating provenance visibility. MemArchitect and Governed Shared Memory [@memarchitect; @memclaw] govern storage and sharing; we govern the consolidation decision. **Diagnostics.** WhenLoss [@whenloss] separates write/retrieval bottlenecks; we focus on the write-decision. **Foundations.** Boundary detection draws on event-segmentation cognition [@zacks; @tulving; @schacter] and prior agent-memory systems [@emllm; @genagents; @hipporag]; the four-level compression hierarchy is from the Experience Compression Spectrum [@compspectrum; @externalization]. The state-not-storage framing and the tripartite (episodic/semantic/procedural) state organization that this program operationalizes are due to the cognitive-state-plane formulation of [@stateplane], which motivates studying the consolidation decision as a first-class, governable operation.

# Reproducibility and Controlled Release {#sec:repro}

Every numerical claim in this paper traces to a persisted, machine-readable result file, reproduced bit-exactly from disk and independently re-derived by a second computation path; integrity self-tests and the Phase-1 anti-leakage gates pass on a clean environment. To protect a production lineage, three classes of detail are described functionally and held under **controlled release** (available to reviewers and collaborators on request, under terms): (1) the exact gate thresholds and the instability / detail-grounding *signal definitions*; (2) benchmark-generator parameters (cluster-type constants, oracle-computation specifics) sufficient to clone the generator; (3) the production integration mapping. These are implementation constants and recipes, not findings: the reported results, axes, verdicts, and the insurance property are fully specified here. We believe this balances scientific credibility (verifiable, reproducible-on-request results) against the legitimate protection of a non-trivial engineering artifact.

# Discussion: The Epistemics Throughline

Read end to end, the program's contributions are not four solutions but four ways to know. Phase 1 gave a discipline for *not self-deceiving*; Phase 2 a method for *diagnosing why a learned mechanism fails*; Phase 3 an *instrument* for scoring consolidation quality against a known optimum; Phase 4 a means to *audit, reverse, and constrain* learned beliefs, with a proof that the governance contribution does not depend on the contested validity of the quality metric. Each phase's honesty became the next phase's foundation: the anti-leakage gates protected the policy claims, the failure diagnosis shaped the benchmark, the benchmark made governance measurable. In a fast-moving field, this is the durable bet, rigorous ways to know, which outlast any single result.

# Limitations

\(i\) **[CQS]{.smallcaps} does not predict external transfer accuracy**: after redesigning the reuse term to remove the collapse that blocked a powered study, a two-benchmark test at $n{=}12$ returns a resolved negative (pooled $\rho = -0.24$, CI spanning zero; Section [5.4](#sec:validity){reference-type="ref" reference="sec:validity"}). [CQS]{.smallcaps} is therefore validated as a consolidation-decision score, not as a predictor of downstream answer quality, and must not be cited as the latter; the governance contribution (Section [5.3](#sec:insurance){reference-type="ref" reference="sec:insurance"}) is independent of this and, if anything, is reinforced by it. (ii) **G2 is demonstrated on a constructed variant** stronger than the main benchmark's break pattern; a harder, naturally-occurring contradiction test remains. (iii) **Synthetic-first**: ConsolidationBench isolates the decision by holding transforms and base-model capability constant, trading ecological validity for diagnostic power. (iv) **Governance verified on one policy** so far; the wrapper is policy-agnostic in principle but tested on a single consolidation policy. (v) Phase 1's detector did not clear its bar; we report it as a negative.

# Conclusion

We set out to give a long-horizon agent a memory and ended with something more useful: a set of tools for *knowing* whether an agent's memory can be trusted, an anti-leakage discipline, a failure-diagnosis method, an oracle-grounded quality benchmark, and a mechanism that makes the act of abstraction auditable, reversible, and poison-resistant, shown to stand independent of the quality metric's contested validity. The wins are reported with their limits; the failures with the same care as the wins. As agents increasingly learn from their own experience and act on what they conclude, the question this program answers becomes urgent rather than academic: *how do we know what an agent has decided to believe, and can we hold it accountable?* Build the thing, and build the thing that checks the thing.
