# Beyond the Known 与 DROID：细粒度域外意图拒识评测与双表示校准基线

- **标题 1**：*Beyond the Known: Investigating LLMs Performance on Out-of-Domain Intent Detection* (LREC-COLING 2024, arXiv:2402.17256)
  - **作者 / 机构**：Pei Wang, Keqing He 等（北京邮电大学 BUPT & 美团 Meituan）
  - **PDF**：`papers/benchmark/Beyond_the_Known_2024.pdf`（源码：`papers/benchmark/2402.17256/source/lrec-coling2024-example.tex`）
- **标题 2**：*DROID: Dual Representation for Out-of-Scope Intent Detection* (2025-10, arXiv:2510.14110)
  - **作者 / 机构**：Wael Rashwan, Hossam M. Zawbaa, Sourav Dutta, Haytham Assem
  - **PDF**：`papers/benchmark/DROID_2025.pdf`（全文：`papers/benchmark/2510.14110/2510.14110.md`）
- **核心定位**：按 **25% / 50% / 75%** 已知意图切分（将同一业务域内未入选的细粒度意图作为 `Near-OOD` / Unselected Intents，UI），系统揭示大模型在“零样本/少样本域外拒识”上的长尾崩溃规律，并给出轻量双编码器（`USE + 领域自适应 TSDAE`）配单阈值校准的强判别式基线。

---

## 一、核心背景与研究痛点

在多意图对话与保障调度系统中，“域外（Out-of-Domain / Out-of-Scope, OOD/OOS）”拒识的真正难点不在于识别完全无关的闲聊（`Far-OOD`），而在于**同域细粒度未知意图（`Near-OOD` / Held-out Unselected Intents）**：用户话术与已知业务高度相似，但属于系统尚未支持的相邻能力（例如银行场景中已知“补卡”，未知“临时冻卡”；网元保障中已知“游戏加速”，未知“跨国专线回源”）。

两篇论文分别从**大语言模型实证评测**与**轻量双编码器判别基线**两条路线切入该问题：
1. **Beyond the Known (`2402.17256`)** 首次在 `CLINC150` 与 `Banking77` 的 `25% / 50% / 75%` 已知意图切分下，把 `ZSD-LLM`（零样本）和 `FSD-LLM`（少样本）与 `SCL / KNN-CL / UniNL` 正面对比（`Sec. 2–4`）。
2. **DROID (`2510.14110`)** 针对判别式模型在“Known 准确率与 Unknown 拒识率之间此消彼长”以及少样本下崩溃的痛点，提出冻结双编码器 + 1.56M 轻量头 + 混合离群样本 + 单阈值 $T$ 校准方案（`Sec. 3`）。

## 二、协议与方法对比

```text
  [数据切分协议: 按 25% / 50% / 75% 意图类作为 Known (IND), 其余 Held-out 类作为 Near-OOD (UI)]
           │
           ├──► Beyond the Known (2402.17256): ZSD-LLM / FSD-LLM 生成式评测
           │       • Prompt 给出 K 个已知意图标签 (+ 0/1/3/5 条示例)
           │       • 要求 LLM 判为已知意图或 "unknown"
           │       • 暴露三大缺陷: 越细粒度越误判、IND 越多 OOD-Recall 暴跌、8.49% 幻觉新标签
           │
           └──► DROID (2510.14110): 冻结双编码器 + (K+1) 分类 + 单阈值校准
                   • Stage 1: 无监督 TSDAE 在目标域无标注文本上降噪自适应 (768-d)
                   • Stage 2: 冻结 USE (512-d) + TSDAE (768-d) → 各自 5 层 MLP 投影至 256-d → 拼接 512-d
                   • OOS 负样本: 特征空间凸插值 h^OOS = θ·h_β + (1-θ)·h_α + SQuAD 2.0 开放域负样本 (500+500/epoch)
                   • Stage 3: 验证集校准单一标量阈值 T (=0.7), max_{i≤K} p(C_i|u) < T 即拒识为 OOS
```

### 1. Beyond the Known 的实验设计（`2402.17256` `Sec. 2–3`）
- **数据集与切分**：`CLINC150`（150 个意图 / 10 个领域）与 `Banking77`（77 个细粒度单领域意图），按 **25% / 50% / 75%** 抽取 Known 意图，其余划为 OOD 测试；另外使用 CLINC 原生 150 个全量意图 + 外部 OOS 测试大规模指令失败率。
- **核心指标**：`ALL-ACC`、`ALL-F1`、`IND-ACC`、`IND-F1`、`OOD-Recall`、`OOD-F1`。

### 2. DROID 的架构与公式（`2510.14110` `Sec. 3–4`）
- **双编码器融合（`Eq. 1–4`, `Fig. 2`）**：
  - 通用分支：冻结 `USE`（512 维）→ 5 层 MLP `(512, 256, 256, 256, 256)` → $h'_{\text{USE}} \in \mathbb{R}^{256}$；
  - 领域分支：无监督降噪预训练的 `RoBERTa-TSDAE`（768 维，损失 $L_{\text{TSDAE}} = 1 - \cos(E(u), E(\tilde{u}))$，监督阶段冻结）→ 5 层 MLP → $h'_{\text{TSDAE}} \in \mathbb{R}^{256}$；
  - 拼接融合 $h_{\text{fused}} = [h'_{\text{USE}}; h'_{\text{TSDAE}}] \in \mathbb{R}^{512}$，经 3 层 MLP `(128, 128, 128)` 输出 $(K+1)$ 维 softmax 概率，总可训练参数仅 **1,559,808（~1.56M）**。
- **双源负样本构建（`Sec. 3.3 & 4.3`, `Eq. 3`）**：
  1. **特征空间合成难负样本**：从不同已知类随机采样融合特征 $h_\alpha, h_\beta$，做凸插值 $h^{\text{OOS}} = \theta h_\beta + (1-\theta) h_\alpha, \theta \sim U(0,1)$，精准填充类间低密度边界；
  2. **开放域负样本**：从 `SQuAD 2.0` 抽取长度 $5 \le |u| \le 64$ 的去重问句；每轮均衡采样 $N_{\text{syn}}=500, N_{\text{open}}=500$（mini-batch 中 OOS 占比 20%–40%）。
- **单阈值校准规则（`Eq. 1`, `Sec. 3.6 & 4.6`）**：仅用验证集调优单一阈值 $T \in \{0.00, 0.02, \dots, 1.00\}$（实验最优 $T = 0.7$），推理时若 $\max_{i \le K} p(c=C_i \mid u) \ge T$ 则输出对应已知意图，否则统一拒识为 `OOS`。

- **四大关键发现（`Sec. 4–5`）**：
  1. **Known 意图越多，LLM 域外拒识崩溃越严重**：在单域细粒度的 Banking77 上，随着已知意图从 25% 增至 75%，ChatGPT 的 `OOD-Recall` 从 `39.09%` 一路跌至 `15.62%`，大量 `Near-OOD` 被强行归入某个似是而非的已知意图；
  2. **少样本（FSD-LLM）存在双刃剑（`Table 3`）**：当 $N=5$ 个已知意图时，`5-shot` ChatGPT 可略超 UniNL（`ALL-ACC 89.11` vs `88.35`）；但当 $N=40$ 时，`5-shot` ChatGPT 的 `OOD-Recall` 跌至 `32.80%`（远低于 UniNL 的 `77.32%`），过多示例反而造成向 OOD 的负迁移；
  3. **指令超长引发任务失败（`Sec. 4.1`）**：在 CLINC 全量 150 意图设定下，ChatGPT 有 **8.49%** 的测试样本既不输出已知标签也不输出 `unknown`，而是直接“自造新意图”；
  4. **错因分类（`Sec. 6.1`, `Fig. 5`）**：大模型通识与业务领域知识冲突导致三类错误——错误联想（False Association）、焦点偏移（Focus Deviation）与领域知识缺失（Lack of Domain Knowledge）。

- **关键消融发现（`Sec. 5.2–5.6`, `Table 3`）**：
  - 在最具挑战性的细粒度单域 `BANKING-77 (75% Known)` 上，传统 `(K+1)-way` 与 `DA-ADB` 的 Unknown F1 分别只有 `59.89%` 和 `69.37%`，而 **DROID** 仍稳居 **`91.21%`**；
  - 双编码器中，**目标域无监督降噪自适应（`TSDAE(In-domain) + USE`）** 是核心增益来源：即使仅用 `CLINC-150` 自适应的 TSDAE 配 USE 在 Banking77-25% 上也可达 `90.82 / 95.55`，显著优于通用 `RoBERTa-TSDAE + USE`（`65.61 / 89.84`）和单 `USE`（`52.74 / 90.00`）；
  - 仅用 20% 标注比例（`label ratio = 0.2`）时，DROID 在 CLINC-150 上的 Known F1 仍接近 **90%**，抗稀缺能力远超 ARPL / DOC / MDF。

## 五、对我们主报告与业务系统的落地启发

1. **评测集设计（对应主报告 1.1 方向二 & 1.3）**：
   - 不能只用“天气/笑话”等 `Far-OOD` 测拒识，必须引入 **`25% / 50% / 75%` 留出切分（Held-out Near-OOD）**：从业务能力库中随机留出未上线或无权限的相邻网元保障子意图作为测试集未知类，检验路由层是否能精准拒识而非强行张冠李戴。
   - **监控“自造新标签”任务失败率**：若意图数较多，需单独统计模型输出既不在允许意图集内、也未触发合法 `OOS` 拒识的越界响应比例。
2. **快路径架构与边缘拒识（对应主报告快慢路径分流）**：
   - 单靠大模型零样本/少样本 Prompt 做多类意图 + `Near-OOD` 判别不仅延迟高，而且当意图规模 $\ge 30$ 时 `OOD-Recall` 会断崖下跌；
   - **可借鉴 DROID 的双表示 + 单阈值前置门控**：在快路径路由前置一个极轻量（~1.5M 参数）的双编码器（通用向量 `text-embedding-v4` + 领域无监督自适应小模型）+ 验证集校准阈值 $T$，配合“已知意图类间凸插值合成难负样本”，以极低成本守住 `Near-OOD` 拒识底线。
