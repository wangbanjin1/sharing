# 27. BehaviorMem：面向真实长期行为流的用户记忆构建与“记忆/推断”双轨评测（BehaviorMemBench）

> **来源定位**：`papers/benchmark/BehaviorMem_2026.pdf`（arXiv: `2610.34790`，暂无公开代码仓链接）  
> **作者机构**：Sizhe Wang, Xinghao Fang, Rui Qiu, Zhenjia Ma, Dagui Chen, Kun Kuang, Hongcheng Guo（浙江大学 & 阿里巴巴/淘宝）  
> **核心定位**：指出既有记忆基准多基于对话文本或合成轨迹且未区分“记住已发生事实”与“跨未知领域推断偏好”，基于 **淘宝 3 年+ 真实行为日志（Feb 2023 – Jun 2026，1,194 用户、17,462 批次、16,268 次转移）** 提出 **BehaviorMemBench**（以“50 次访问或 120 天且间隔 $>15$ 分钟”切分批次，拆分为 **`Remember Pool`** 与 **`Infer Pool`**），并提出“显式事实 $\times$ 隐式推断 / 长期 $\times$ 短期”双轴记忆架构 **BehaviorMem**，在保持 `Remember` 与 `Infer` 双领先的同时，比 `Long Context` / `LightMem` 节省 **$>70\%$** 记忆输入 token。

---

## 一、BehaviorMemBench：真实行为流切分与“记忆/推断”双池评测（`Sec 3`）

```
真实淘宝行为流 (浏览/点击/收藏/加购/购买, 2023-02 ~ 2026-06, 913,271 次访问)
   │
   ├─► 批次切分规则: 累计达 50 次有效访问 OR 跨度达 120 天 → 在下一个 >15 min 间隔处闭合为 B_t
   │
   ├─► 因果用户状态接口 (Eq. 1): 仅用历史 B_{≤t} 更新状态 M_t 并输出与查询无关的读出 O_t = Φ(M_t)
   │
   └─► 下一批次真实正样本 Y_{t+1} (排除浅层点击, 仅取收藏/加购/购买/深度浏览 L2 类目)
         ├─ [Remember Pool]: 已访问 L2 类目 + 强观测 L1 域内未见 L2 类目 (配 cluster/history/random 1:3 干扰项)
         └─ [Infer Pool]:    弱观测相关域 (related) + 未访问但语义连通域 (new) (配 history/random 1:3 干扰项)
```

- **核心指标（`Eq. 3`）**：固定冻结 `TaskReader`（不告知方法身份）从候选池选出 $n_t^p = |Y_{t+1}^p|$ 个类目，计算正样本召回率 $R_p \uparrow$ 与各干扰簇误选暴露率 $E_{p,f} \downarrow$。

## 二、BehaviorMem 双轴记忆与休眠治理机制（`Sec 4`）

1. **双轴状态结构（`Eq. 4`）**：$M_t = (F_t, A_t, D_t, \mu_t)$，其中：
   - **显式程序事实 $F_t = (F_t^{\mathrm{L}}, F_t^{\mathrm{S}})$**：$F_t^{\mathrm{L}}$ 累计历史类目与品牌统计，$F_t^{\mathrm{S}}$ 保留近期商品交互明细；
   - **隐式推断声明（`Claims`）$A_t$（活跃）与 $D_t$（休眠）**：沿 `行为 → 模式 → 主题 → 特征` 逐级抽象，挂载到 `type–domain–attribute` 语义路径并保留原始行为引用，分为 4 类：**`T1` 人口统计、`T2` 社会关系、`T3` 兴趣偏好、`T4` 情境状态**，由 $\mu_t$ 追踪路径连续性。
2. **局部修正与休眠机制（`Sec 4.3`）**：**仅当直接矛盾时才退役旧声明，缺少新观测绝不删除记忆**；长期连续路径保持 `Active`，阶段性情境路径转入 `Dormant`（暂不向读出暴露但保留证据，新证据到来可再激活）。
3. **查询无关读出（`Sec 4.4`, `Eq. 7`）**：仅暴露 $F_t$ 与活跃 $A_t$；平均仅 **`2,018` / `1,850` tokens**（相比 `Long Context` `7,338` 与 `LightMem` `7,084/6,812` 压缩 $>70\%$）。

## 三、核心实验与消融发现（`Sec 5`, `Table 1` & `Fig. 3`–`5`）

以下摘录两个典型 `Builder / Reader` 组合的主表结果（`Table 1`，`Remember R ↑` 与 `Infer R ↑ / R_related / R_new`）：

| 方法类别 | 方法 | `Qwen3-32B` Builder + Reader (`Rem R` / `Inf R` / `R_new`) | `Qwen3-32B` Builder + `Qwen3.7-Plus` Reader (`Rem R` / `Inf R` / `R_new`) |
| :--- | :--- | :---: | :---: |
| **统计/原文基线** | `Long Context` | **0.647** / 0.426 / 0.394 | **0.694** / **0.484** / 0.419 |
| | `Frequency Profile` | 0.644 / 0.424 / 0.400 | 0.652 / 0.441 / 0.398 |
| **通用智能体记忆** | `A-Mem` | 0.535 / 0.442 / **0.416** | 0.565 / 0.462 / 0.425 |
| | `Mem0` | 0.438 / 0.408 / 0.389 | 0.444 / 0.421 / 0.392 |
| | `LightMem` | 0.604 / 0.422 / 0.395 | 0.646 / 0.476 / 0.430 |
| **个人画像记忆** | `Persona Tree` | 0.497 / 0.414 / 0.386 | 0.522 / 0.429 / 0.410 |
| **本文方法** | **`BehaviorMem`** | **0.612** / **0.443** / **0.416** | **0.650** / **0.483** / **0.447** |

- **核心结论 1（“记住”与“推断”排名分化）**：`LightMem` 在 `Remember` 上高于 `A-Mem`（`0.604 vs 0.535`），但在 `Infer` 上反被 `A-Mem` 超越（`0.422 vs 0.442`），证明只靠单池评测会掩盖记忆表达的偏科。
- **核心结论 2（显式事实与隐式声明分工，`Sec 5.3`）**：遮蔽显式记忆使 `Remember R` 从 `0.612` 暴跌至 `0.529`（`T3/T4` 影响大于 `T1/T2`）；而遮蔽隐式记忆（尤其 `T1/T2` 人口/社会属性）显著削弱 `Infer R`（`0.443 → 0.432`），且遮蔽 `T3/T4` 反而使 `R_new` 从 `0.416` 小升至 `0.423`。
- **核心结论 3（频率统计基线的强参照价值）**：`Frequency Profile` 与 `Long Context` 在 `Remember` 上极具竞争力，但 `Frequency Profile` 在未见相关类目上迅速失灵（`Sec 5.4`）。

## 四、对我们主报告与联接 Agent 项目的落地启发

1. **直接复用 `Remember Pool` 与 `Infer Pool` 评测解耦思路**：在网元记忆评测中，将“复现历史已保障过的应用/固定时段（`Remember`）”与“基于人口/作息/业务关联迁移推断未直接出现过的新业务保障偏好（`Infer`）”拆开评测，并与强统计基线（`Frequency Profile`、`Long Context`）同台对照。
2. **借鉴“未见新观测不删旧记忆 + Active/Dormant 休眠态”机制**：用户某段时间不出差或不开特定会议，不代表长期偏好失效；仅在用户明确改口矛盾时才淘汰旧规则，其余阶段性约束转入 `Dormant` 休眠态以免污染常规提示词长度。
