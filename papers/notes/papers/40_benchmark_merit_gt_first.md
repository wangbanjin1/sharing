## 1. 两篇论文针对的评测盲区与核心方法

| 维度 | MERIT (`2609.05441`) | Ground Truth First (`2607.21962`) |
| :--- | :--- | :--- |
| **批判的传统缺陷** | `LoCoMo`/`LongMemEval` 只测对话 QA 召回，不测记住的事实是否真正改变工具调用决策；缺乏泄漏校验、更新事实覆盖与记忆侧全链路成本计量 | 传统评测“先生成对话、再抽取答案键”，导致 `LoCoMo` 存在 **6.4%**（99/1,540）标签错误；真实实体被预训练记忆泄漏；且仅测短历史（`<150` 轮对话时全量上下文可直接碾压） |
| **核心评测机制** | 三域工具执行任务（`D1 commerce`、`D2 IT ops`、`D3 assistant`），每条任务通过自动化泄漏校验确保无记忆基线 `C0 ≈ 0.00`；设置简单→中等→**更新事实（`hard`）**难度梯度与污染注入；全程计量每次写入/检索的 token 与美元成本 | **先生成确定性生活剧本（含有效期、易变性类别、发送/接收方溯源边界）→ 再由 LLM 渲染聊天与邮件 → 忠实度校验器逐条核实 → 机械实例化跨周 `as-of-date` 问题集**（3 周 / 6 周 / 9 周） |
| **实验规模** | 总计 **23,440** 个评分回合（`$42.57` API 成本）：`9,940` 回合双代先导实验 + `13,500` 回合预注册 `3 模型 × 3 域 × 3 难度 × 3 种子` 全网格 | 短历史 `275` 题 × 3 重复 = **825** 条回答/架构；长历史（9 周）`6` 名用户 × 3 重复（每单元格 $n=324$）；全协议共 **52,797** 次 LLM 调用 |

## 2. MERIT 核心实证：随机种子方差、忽略率与全量重放性价比

### 2.1 记忆条件定义与跨模型/跨种子鲁棒性（`2609.05441.md` §5.3–§5.7 & Table 2）

MERIT 对比了 6 种记忆条件：`C0`（无记忆基线，`TSR = 0.00–0.05`）、`C1`（全量历史重放，`TSR = 1.00`）、`C2`（向量嵌入检索）、`C3`（LLM 摘要覆盖写）、`C4`（结构化事实存储）与 `C5`（混合存储）。

1. **向量检索在“更新事实（`hard`）”上的剧烈种子方差（§5.7）**：
   - 在 `3` 个随机种子（`gpt-4.1-mini`）网格上，**`C2`（向量检索）的跨种子最大两两 TSR 差值均值高达 `0.16`**，最坏单元格（`D1-hard`）出现 **`0.45`** 的极端波动（三个种子分别为 **`0.45 / 0.90 / 0.75`**）。相比之下，`C1` 平均方差仅 `0.07`，支持写入覆盖的 `C3`/`C4` 仅为 `0.11–0.12`。单种子评测极易得出完全误导的结论。
2. **跨模型在 `hard`（更新事实）层级上的表现（Table 2，记忆侧固定为 `gpt-4.1-mini`）**：

| 条件 | 领域 | Claude Haiku 4.5 | GPT-4.1 | `gpt-4.1-mini` (`±sd`) |
| :--- | :---: | :---: | :---: | :---: |
| **C2 向量嵌入检索** | `D1` | `0.90` | `0.70` | `0.70 ± 0.23` |
| **C2 向量嵌入检索** | `D2` | `0.95` | `0.45` | `0.38 ± 0.08` |
| **C2 向量嵌入检索** | `D3` | `0.30` | `0.60` | `0.37 ± 0.03` |
| **C3 LLM 摘要覆盖** | `D1 / D2 / D3` | `1.00 / 1.00 / 1.00` | `1.00 / 0.90 / 1.00` | `0.98±0.03 / 0.80±0.10 / 1.00±0.00` |
| **C4 结构化事实库** | `D1 / D2 / D3` | `1.00 / 1.00 / 0.70` | `1.00 / 1.00 / 0.90` | `0.93±0.08 / 0.90±0.05 / 0.90±0.09` |

3. **检索对了却不用（`Ignore Rate = 0.45`）与过时污染（§5.4–§5.5）**：
   - 在 `hard` 层级的 55 个探针回合中，虽然最新正确值已经出现在 `C2` 检索出的上下文块里，但 Agent 仅在 30 个回合中实际按其行动（**忽略率 `0.45`**）；即便是干净全量重放 `C1`，在多事实中等难度下也会忽略高达 `0.50` 的已持有事实。
   - 混合存储 `C5` 在 `30%` 过时记忆污染（`ρ = 0.3`）下受损最重（`SMH = +0.25`, Holm 校正 $p = 0.030$），反而不如单纯的结构化事实库 `C4`。
4. **成本—边际效用（`CAMU`）结论（§5.6）**：全量重放 `C1`（`$0.00126`/回合，`2,914` tokens）从未成为经济最优解，各域最优记忆系统的每美元边际收益是全量重放的 **`2.7–3.9×`**。

## 3. Ground Truth First 核心实证：历史长度引发的排名翻转与溯源安全

### 3.1 短历史榜首 vs. 长历史（9 周）排名翻转（`05_results.tex` Table 1 & Table 2）

```text
  第 3 周 (短历史):  [curated map 81.2%]  >  [hybrid v2 80.2%]  >  [graph 75.9%]  >  [vector 75.3%]
                            │                     │                   │
                            ▼ (固定预算驱逐早期记录: 96.3% -> 72.2%)     ▼ (无界溯源图保真上升)
  第 9 周 (长历史):  [hybrid v2 93.2%]    >  [graph 90.4%]      >  [curated map 78.4%]  >  [vector 74.7%]
```

| 记忆架构 | 短历史（825 题） | Week 3 ($n=324$) | Week 6 ($n=324$) | Week 9 ($n=324$) | 早期章节探针（Wk3 → Wk9） |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **none（无记忆控制）** | `15.2%` | `16.0%` | `16.4%` | `16.7%` | — |
| **curated map（定额工作视图）** | `94.2%` | **`81.2%`** | `79.6%` | `78.4%` | **`96.3% → 72.2%`**（预算驱逐丢失旧事） |
| **vector（无界向量检索）** | `91.0%` | `75.3%` | `68.8%` | `74.7%` | `88.9% → 70.4%`（新近相似内容淹没旧记录） |
| **graph（溯源类型化图谱）** | `93.2%` | `75.9%` | `79.0%` | **`90.4%`** | **`94.4% → 100.0%`** |
| **hybrid v2（分层协同架构）** | **`96.8%`** | `80.2%` | **`85.8%`** | **`93.2%`** | **`100.0% → 100.0%`** |
| **hybrid v1（朴素拼接图与视图）** | `89.5%` | — | — | — | 低于双亲本：字符串拼接放大抽取噪声 |

- **统计学显著的排名翻转（`05_results.tex` §5.4）**：`Week 3` 时 `curated map > graph`（$p = 0.019$），到 `Week 9` 翻转为 `graph > curated map`（$p < 10^{-4}$），6 名用户全部满足 `graph ≥ map`；跨模型家族裁判复核后交互效应高达 **`+24.1 pp`**（精确符号翻转检验 $p = 0.031$）。
- **写入质量决定下游准确率（§5.5）**：对 66 份写入记忆做逐事实审计表明，两阶段精选写入的事实召回率为 **`84.5%`**（4.0 错/次），单次抽取仅为 `74.6%`（8.5 错/次）；当底层事实写错或漏写时，下游 QA 失败率达 **`24.2%`**，而写对时仅 **`1.6%`**（风险比约 `15×`，`79%` 的下游错误源自写入缺陷）。
- **溯源边界防御注入与“高准确率不等于会拒答”（§5.7）**：
  - 将第三方邮件标记为 `claim`（带发送者溯源）的图结构成功拦截全部 **14** 个注入探针（42 次测试 **0** 误断言），而扁平文本摘要剥离了来源边界，在 **2/14** 探针与分级钓鱼阶梯中 `3/6` 攻破。
  - 虽然 `hybrid v2` 总体准确率最高，但一旦出错时 **`93.9%`（124/132）** 都是“自信地编造错误细节”，极少拒答（972 题中仅 8 次拒答，对比 `vector` 的 98 次），证明生产系统必须在读出阶段加装**基于证据的拒答门控**。

## 4. 对我们当前方案的直接启发

1. **必须坚持“先定 GT 剧本、再渲染对话与单据”的合成管线**：我们的 `storyline → sample` 数据生成器已经契合 `Ground Truth First` 思路，应进一步把“事实有效期、易变性分类与发送/接收来源边界”写入脚本清单，并在生成后做自动泄漏校验（保证无记忆基线准确率归零）。
2. **评测报告必须报告多种子方差与长短历史双窗口**：禁止单次随机种子跑通即报最高分（MERIT 证明向量检索在更新任务上单靠换种子就能差 `0.45`）；同时必须覆盖多周跨度，防止定额摘要架构在短历史下掩盖早期记忆驱逐缺陷。
3. **拆解“检索召回率”与“检索后采用率（Ignore Rate）”**：既要测记忆系统是否把最新规则/槽位送进了上下文，也要测 Agent 是否真正依据该记忆调整了最终工具参数，避免“查到了却不用”。
