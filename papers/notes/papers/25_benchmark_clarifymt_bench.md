# 25. ClarifyMT-Bench：面向多轮模糊交互与六类用户行为的多轮消歧基准及 ClarifyAgent

> **来源定位**：`papers/benchmark/ClarifyMT_Bench_2025.pdf`（arXiv: `2512.21120`，暂无随附开源代码仓链接）  
> **作者机构**：Sichun Luo, Yi Huang, Mukai Li, Shichang Meng, Fengyuan Liu, Zefa Hu, Junlan Feng, Qi Liu  
> **核心定位**：针对现有澄清基准多局限于单轮且默认用户配合无噪声的不足，提出覆盖 **5 维模糊分类（12 个子类）**与 **6 类真实用户行为模拟器**的 **ClarifyMT-Bench**（`1,020` 条初始模糊请求 $\times$ `6` 类人设 = **`6,120` 条多轮对话**）；评测 10 个主流大模型揭示了普遍的 **Under-Clarification（过早作答）**与跨轮衰减现象，并提出集成“用户画像推断 + 有限状态槽位追踪”的 **ClarifyAgent**，将 `Llama-3.1-8B` / `Qwen-2.5-7B` 平均澄清决策准确率分别提升至 **`88.4%`** 与 **`88.0%`**。

## 一、五维模糊分类与有限状态决策建模（`Sec 3.1`–`3.2`）

### 1.1 五维模糊分类（`Sec 3.1`）

| 模糊维度 | 核心成因 | 12 个评测子类（`Table 2` 表头缩写） |
| :--- | :--- | :--- |
| **语言模糊（`Linguistic`）** | 词汇多义、句法歧义或语义未定 | `Lex.`（词汇）、`Syn.`（句法）、`Sem.`（语义） |
| **意图模糊（`Intent`）** | 目标不明确、任务边界不清或潜在冲突 | `Goal`（目标）、`Sco.`（范围）、`Con.`（冲突） |
| **上下文模糊（`Contextual`）** | 实体指代、空间、时间等上下文缺失或漂移 | `Ent.`（实体）、`Spa.`（空间）、`Tmp.`（时间） |
| **认知鸿沟（`Epistemic`）** | 背景知识假设不对称、生僻实体或主观评判标准 | `Kno.`（知识）、`Unf.`（生僻实体）、`Val.`（主观标准） |
| **交互模糊（`Interactional`）** | 多轮反馈中用户自身回复含糊、跑题、矛盾或事实错误 | 通过下述 **6 类用户行为模拟器**在多轮中动态注入 |

### 1.2 序列化决策状态与两类错误（`Sec 3.2`, `Eq. 1`–`3`）

每个对话轮次 $t$ 维护槽位状态向量 $x_t = [f_t(s_1), \dots, f_t(s_n)]$，其中每个槽位状态 $f_t(s_i) \in \{\texttt{unfilled}, \texttt{filled}, \texttt{conflict}\}$。理想停止条件为所有必需槽位 $S^*$ 均为 `filled` 且不存在任何 `conflict` 槽位：
- **Under-Clarify（过早作答）**：真实动作 $y_t = \texttt{Clarify}$，但模型预测 $\hat{a}_t = \texttt{Answer}$；
- **Over-Clarify（冗余追问）**：真实动作 $y_t = \texttt{Answer}$，但模型预测 $\hat{a}_t = \texttt{Clarify}$。

## 二、数据集构建与六类用户行为模拟器（`Sec 4`, `Table 7`）

1. **单轮模糊池构建（`1,020` 条）**：由 `GPT-5`（约 45%）、`GPT-4.1`（约 25%）、`DeepSeek-V3`（约 25%）及开源 `CLAMBER`（约 5%）联合生成（`Appendix A`），经 `all-MiniLM-L6-v2` 余弦相似度 $\tau_{\text{sem}}=0.7$ 去重及双人校验（10% 抽样复核一致率 $P_o=0.8627$，Cohen's $\kappa=0.5980$），12 个子类各严格保留 **85 条**（共 `1,020` 条）。
2. **六类受控用户模拟器扩展（`6,120` 条多轮，平均 `2.67` 轮 / `66.1` tokens）**：

| 用户类型 | 行为特征 | 对话轮数 | 期望策略方向 |
| :--- | :--- | :---: | :--- |
| **`Precise (P)`** | 一次性给出清晰、准确、完整槽位值 | 2 轮 | 应及时停止追问直接作答 |
| **`Partial-Vague (PV)`** | 回复部分相关但仍宽泛犹豫（如“春天去日本某地”） | 3 轮 | 继续聚焦追问缺失细节 |
| **`Off-Focus (OF)`** | 跑题反问或答非所问（如“日本现在安全吗”） | 3 轮 | 礼貌拉回主线并继续澄清 |
| **`Contradictory (CT)`** | 同轮或跨轮自相矛盾（如“既要便宜又要豪华”） | 3 轮 | 识别 `conflict` 槽位并追问确认取舍 |
| **`Factually-Wrong (FA)`** | 给出事实错误的条件（如“去京都看埃菲尔铁塔”） | 3 轮 | 指出事实冲突并重新确认真实地点 |
| **`Refusal (RF)`** | 拒绝补充细节，催促助手自行决定（如“随便定吧”） | 2 轮 | 尊重用户意愿停止追问，直接作答 |

- **关键发现 2（激进直接作答与过度追问的两极分化）**：`Qwen-2.5-7B` 倾向盲目直接作答，导致 `P/RF` 虚高（`96.6% / 72.9%`）而所有需要继续澄清的场景（`PV/CT/FA`）跌破 `43%`；而 `Gemini-2.5-Flash` / `Claude-Sonnet-4.5` 极度谨慎，在 `RF`（用户明确拒答催促直接办）上分别仅 `14.5%` 和 `35.6%`。
- **关键发现 3（澄清问题质量评估，`Task 2`）**：每类抽样 30 条由 `GPT-4.1`（0–5 分）与人工打分，两者 Pearson 相关系数达 `0.658`。

### 3.2 ClarifyAgent 架构与消融实验（`Sec 6`, `Table 4`–`5`）

```
对话输入 ─► [Perceiver: 槽位状态提取 (filled/unfilled/conflict)]
               │
               ▼
            [Tracker: 有限状态机 FSM 维护槽位 & 判定 RSC 完备性] ◄─┐
               │                                                  │
用户最新回复 ─► [Forecaster: 实时推断用户属于 6 类行为人设中的哪一类] ─┼─► [Planner: 决策 Clarify 或 Answer] ─► [Output]
```

| 底座模型 | 方法 | `P` | `PV` | `OF` | `CT` | `FA` | `RF` | **Avg.** |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| `Llama-3.1-8B-It` | `Base / CoT / AT-CoT` | `48.3 / 12.7 / 74.5` | `75.6 / 80.2 / 80.4` | `87.5 / 89.0 / 84.8` | `86.4 / 88.6 / 81.8` | `84.8 / 90.1 / 87.0` | `44.4 / 27.3 / 29.2` | `71.2 / 64.7 / 73.0` |
| `Llama-3.1-8B-It` | **`ClarifyAgent`** | 58.0 | **97.2** | **100.0** | **97.1** | **96.5** | **81.7** | **88.4** |
| `Qwen-2.5-7B-It` | `Base / CoT / AT-CoT` | `96.6 / 89.0 / 93.9` | `36.5 / 55.0 / 73.2` | `60.3 / 63.1 / 69.7` | `42.4 / 65.6 / 54.7` | `38.8 / 62.7 / 50.8` | `72.9 / 63.1 / 43.7` | `57.9 / 66.4 / 64.3` |

- **消融发现（`Table 5`）**：在 `Qwen-2.5-7B` 上拿掉 `Forecaster`（人设推断）后，平均分从 `88.0%` 跌至 `81.5%`，且 6 类人设间标准差（`Std.`）从 `4.92` 翻倍暴涨至 `10.28`（`PV` 跌至 `67.2%`、`CT` 跌至 `72.1%`），证明“先判别用户处于哪种交互态度/配合度，再决定追问或停止”对稳健澄清至关重要。

## 四、对我们主报告与联接 Agent 项目的落地启发

1. **校准主报告中的用户模拟器分类定义**：原清单曾凭印象记为“合作/惜字如金/跑题/暴躁/术语盲/摇摆”，精读原文（`Sec 4.2`, `Table 7`）确认其真实 6 类人设为 **`Precise`（精准配合）、`Partial-Vague`（半模糊/犹豫）、`Off-Focus`（跑题）、`Contradictory`（前后矛盾）、`Factually-Wrong`（事实错误）、`Refusal`（拒绝澄清/催促直办）**；其中 `Contradictory` 与 `Factually-Wrong` 对网元配置场景尤为关键（例如用户说“把腾讯会议限速到 100M 并保证高清不卡”或“帮我加速不存在的套餐业务”）。
2. **引入“交互行为推断 + FSM 槽位状态（`unfilled / filled / conflict`）”双信号决策**：单纯依赖推理模型（`o3`、`DeepSeek-R1` 仅 `64%~68%`）无法解决多轮澄清失衡；联接 Agent 应在工作记忆中显式维护每个保障槽位的三态机，并在用户催促直办（`Refusal`）时基于安全默认值/图像偏好兜底作答，避免陷入死循环追问。
