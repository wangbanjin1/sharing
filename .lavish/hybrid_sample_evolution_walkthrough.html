核心代码：确定性加权采样公式与局部硬约束（src/factor_registry.py）
def _weighted_pick(seed_key: str, options: tuple[str, ...], weights: dict[str, float] | None) -> str:
    w_list = [max(0.0, float(weights.get(opt, 1.0))) for opt in options]
    total = sum(w_list)
    digest = hashlib.sha256(seed_key.encode("utf-8")).digest()
    target = (int.from_bytes(digest[:8], "big") / float(1 << 64)) * total  # 映射至 [0, total)
    acc = 0.0
    for opt, w in zip(options, w_list, strict=True):
        acc += w
        if target <= acc:
            return opt
    return options[-1]

def parse_and_validate_turns(raw_text, draft_turns):
    turns = json.loads(cleaned).get("turns")
    if not isinstance(turns, list) or len(turns) != len(draft_turns): return None
    for orig, cand in zip(draft_turns, turns, strict=True):
        if cand.get("turn_id") != orig["turn_id"] or cand.get("role") != orig["role"] or cand.get("intent") != orig["intent"]:

Review 当前代码中的 4 个简化假设（待加强点）

Code Audit · 待迭代清单
1. 单据数值生成偏静态

_render_ticket_record() 中 delay_an/dn 固定按中位数 0.4/0.6 拆分，正常卡顿 stalling_duration_s 固定为 12.5，resolution 固定 "1080p"，尚未按 resolution_mode=720 或 signal_edge 分布随机波动。

2. 多应用与时间密度未展开

Step 3 节点 app 始终取 frequent_apps 第一名，未按概率混合副应用；L1-1.2_density（前疏后密等）与 L1-6.2_evidence_gap 尚未控制时间间隔分布。

3. 冷启动首段未做前置留白

L1-2 == "冷启动" 目前仅写入 L2-14_missing_forms 标签，Step 3 的 seed_3day 仍会生成初始证据节点，未做冷启动历史全空切片。

4. 闲置画像指标尚未接入

seed_profiles.json 中的 app_session_stats.avg_dur_s、bitrate_median、bandwidth_env 暂未接入单据时长或码率渲染。
