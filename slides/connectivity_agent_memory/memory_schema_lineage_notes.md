# 补充说明

| 记忆类型 | 认知心理学定义 | 当下实践的补充 | 相关论文的支撑 |
| :--- | :--- | :--- | :--- |
| **情景记忆** | 记录特定时间与情境下亲历的单次具体事件（发生了什么、何时发生），在智能体中基础形式为“初始输入（起因）→ 交互动作与环境反馈序列（经过）→ 任务终态（结果）”。 | 1. 分离“事件实际发生时间”与“对话提及时间”，消除跨期时间指代错位；<br>2. 无明确日期的重复事件拼入原始记录唯一行号，防止不同天发生的同类事件被向量去重误合并；<br>3. 显式区分“仅口头咨询/计划”与“实际已发生闭环”，保留底层只读原文供上层事实双向溯源。 | • 基础定义：Tulving (1972, 1983)；CoALA (TMLR 2024, https://arxiv.org/abs/2309.02427 )；Pink 等 (2025, https://arxiv.org/abs/2502.06975 )<br>• 发生/提及时间分离、完成态标记与无日期防误合并：MIRIX / MIRIX-2.0 (https://arxiv.org/abs/2507.07957 , https://arxiv.org/abs/2611.12068 )<br>• 原始未改写节点只读保留与双向溯源：Zep / Graphiti (https://arxiv.org/abs/2501.13956 ) |
| **语义记忆** | 脱离单次具体事件的一般客观知识与稳定事实断言，基础形式为“主体 — 属性/关系 — 目标取值”三元组。 | 1. 增加“场景与时段条件作用域”，隔离同一用户在不同业务场景或周期时段下的同名偏好参数；<br>2. 增加“生效/失效双时间戳与历史旧值归档”，用状态软失效或睡眠期离线归并替代在线硬覆盖，兼顾当前状态准确与历史变迁回溯；<br>3. 增加“来源情景事件编号列表”，区分单次偶发提及与多次重复的长期稳定习惯（联接场景进一步显式保留未观测空值边界）。 | • 基础定义：Tulving (1972)；Collins & Quillian (1969)；CoALA (https://arxiv.org/abs/2309.02427 )；Mem0 / Mem0g (https://arxiv.org/abs/2504.19413 )<br>• 双时态有效期区间与来源事件列表：Zep / Graphiti (https://arxiv.org/abs/2501.13956 )<br>• 多角色条件作用域绑定与历史旧值归档：MIRIX-2.0 (https://arxiv.org/abs/2611.12068 ) |
| **程序记忆**<br>（经验记忆） | 指导在特定条件下如何执行动作的程序性技能知识，基础形式为“触发条件 → 执行动作”产生式规则。 | 1. 增加“显式禁用边界”，在每步推理前自检适用性，防止相似任务盲目套用旧经验引发负迁移；<br>2. 增加“失败根因与异常恢复步骤”，并采用双层粒度控制（开局只给轻量诊断方向，首次测试校验报错无法推进时才单轮注入细节并用完移除）；<br>3. 增加“对话原话/外部运行结果确定性核验”与“后续有效/有害效果追踪”，防止模型自评幻觉污染技能库。 | • 基础定义：Newell & Simon (1972)；Anderson ACT-R (1993)；Laird Soar (2022)；CoALA (https://arxiv.org/abs/2309.02427 )<br>• 显式禁用边界与单步适用性检验：ReasoningBank (ICLR 2026, https://arxiv.org/abs/2509.25140 )<br>• 失败根因、恢复路径与单轮按需注入移除：WASP-Mem (https://arxiv.org/abs/2611.04003 )；REM (NeurIPS 2026, https://arxiv.org/abs/2610.27377 )<br>• 原话引文确定性核验与按采用胜率淘汰删除：MIRIX-2.0 (https://arxiv.org/abs/2611.12068 )；Memp (ACL 2026 Findings, https://arxiv.org/abs/2508.06433 ) |
