# 长期记忆与经典论文机制对照表（Markdown 审校稿）

> **使用说明**：本文件完整对应最终 Excel 工作簿的全部 Sheet 与 16 列 × 3 行结构。我们先在这里逐篇修改、删增、拍板；全部定稿后，再由脚本一键渲染生成最终 `.xlsx` 表格。
> **当前聚焦**：`情景记忆` 行（重点筛选**能解决跨会话指代、时间锚点或历史事件回溯**的经典论文）；`语义记忆` 与 `程序记忆（经验记忆）` 两行暂留空占位。
> **对齐原则**：所有论文子表的 `触发时机与输入`、`标准输出`、`存储形式` 严格对照总表骨架裁剪——**原文有的才写，没有的写“无”或省略**，不凭空捏造。
