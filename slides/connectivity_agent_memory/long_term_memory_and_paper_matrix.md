> 备注：
> 1. CoALA 将长期记忆严格三分为：情景记忆（过去发生的具体事件与轨迹）、语义记忆（关于世界与自身的客观事实）、程序记忆（隐式模型权重 + 显式代码过程）。
> 2.语义记忆的生成，原文未设定累积次数或晋升阈值。Reflexion（单次交互结束即触发）将结论写入记忆。
>    • Generative Agents （按重要度累加阈值触发）：每条新事件写入情景记忆时由大模型打 1~10 分的重要度，当近期未反思事件的重要度得分累加和超过阈值 150 分时才触发一次高层反思
>    • 最近时间分（规则计算）：按距上次访问的小时数 Δt 做指数衰减（0.995^Δt）；
>    • 重要程度分（大模型打分）：写入时由大模型打 1~10 分并归一化到 [0, 1]；
>    • 语义相关度分（向量计算）：当前查询向量与事件向量的余弦相似度归一化到 [0, 1]；
