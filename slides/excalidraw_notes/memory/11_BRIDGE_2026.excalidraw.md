直击核心追问：复杂记忆原语在标准问答基准上到底值不值成本？记忆架构真正分出高下的地方在哪里？ ^txt_0028

1. 解决什么问题 ^txt_0030

1. 现有记忆系统不断堆叠抽取、冲突覆写、反思、知识图谱等重型原语，但缺乏极简强基线检验这些高成本模块是否真有净收益；
2. 现有基准（LoCoMo / LongMemEval）只测“能不能答出关于过去的问题（召回）”，却不测“新任务不提旧规则时，Agent 能否自觉应用记住的规则与模式（执行）”。 ^txt_0031

2. BRIDGE 极简数据结构（零图谱 · 零覆写 · 双存原文） ^txt_0033

3. 核心实证：没有单一记忆架构能通吃所有行为测试 ^txt_0036

• 显式规则应用（RA+ / RA-）：原子事实抽取器（如 LangMem）胜出，因为独立短规则更容易被下游模型注意到并严格执行；
• 隐式模式归纳（PI-S / PI-P）：块摘要/原文记忆（BRIDGE）胜出，因为原子事实抽取在压缩时丢掉了示范代码或流程的原始形态；
• 关键归因：块摘要在规则题上并非“没检索到”，而是“检索到了但下游模型没照做”——只需在呈现时突出规则即可大幅缩小差距。 ^txt_0037

4. 评测方法论突破（生成期约束裁判 + 跨厂商防偏见） ^txt_0039

• 对抗测试不比对参考答案文本，而是针对每条约束逐项判为 applied / violated / n/a；
• 裁判模型强制选用与数据生成器、被测 Reader 不同厂商的模型，消除同家族自偏好偏差。 ^txt_0040

BRIDGE 极简记忆 · 全生命周期流水线（生成 → 更新 → 检索 ｜ 遗忘 · 删除） ^txt_0042

全程零覆写、零删改，靠「原文+笔记双存」「双通道 RRF」「两级渲染+时间升序」取胜 ^txt_0043

双存原文与 XML 笔记 ^txt_0046

算法流程 ^txt_0048

史笔记一起送入单次 LLM 抽取 XML 观测笔记（记录偏好、状态变更与用

阈值与时机 ^txt_0051

• 块上限 2000 token，历史链窗口 W = 10；
• 时机：会话/工具调用自然结束或达 token 上限时触发。 ^txt_0052

2. 更新（纯追加 · 零覆写） ^txt_0054

不设冲突覆写或图谱合并 ^txt_0055

算法流程 ^txt_0057

只做块级追加写入，完全不执行旧记忆修改、冲突覆盖或实体图
谱归并；状态演化完全交由检索时的时间升序呈现让下游模型自
行判断最新状态。 ^txt_0058

阈值与时机 ^txt_0060

• 无更新冲突阈值；
• 时机：新块抽取完成后直接追加。 ^txt_0061

3. 检索（双通道 RRF + 两级时间序渲染） ^txt_0063

前 3 给原文 · 后 7 给笔记 · 按时间升序 ^txt_0064

检索与重排流程 ^txt_0066

1. 双通道召回：Cosine(q, 笔记) 与 BM25(q, 笔记||原文) 各取 Top-60，经 RRF（k=60）融
   合取 Top-10；
2. 两级渲染：Top-10 内按余弦分最高的前 r = 3 块展示完整原文 x，其余 7 块展示 Summary
   笔记 o；
3. 时间重排：将 10 块按全局发生位置 (t, k) 升序排列后交单次 Reader LLM 作答。 ^txt_0067

检索时机 ^txt_0069

每次查询调用单次 Reader LLM 前执行。 ^txt_0070

全量保留块存储 ^txt_0073

原论文核心实证数据（三标准基准 + 5 类测试与多领域） ^txt_0088

• 标准问答基准追平/反超：单次写入/查询仅 1 次 LLM 调用，在 LongMemEval-S 与 BEAM 上位于 SOTA 置信区间内追平复杂系统，在 EverMemBench 上反超最佳记忆基线
  5.7~6.3 分；
• 消融硬数据：去原文槽位（r=0）→ LongMemEval-S 助手单会话题跌 30.2 分；去时间升序重排 → 知识更新题跌 7.7 分；BM25 与 Cosine 互补差距达 38 分；
• 对抗测试结论（覆盖 4 领域、3 裁判与 3 模型家族）：原子事实赢显式规则执行，块摘要赢隐式模式归纳；测试集上把全部 10 块展示原文可让规则应用再涨 13 分。 ^txt_0089

对联接 Agent 架构选型与评测体系的直接落地启发 ^txt_0091

1. 印证「双轨混合记忆」必要性：显式偏好与禁用约束必须抽为原子结构化槽位（如语义记忆表，防“召回了却没执行”），而历史单据与多轮交互过程需保留原文槽位 + 时间升序
   （防细节与模式丢失）；
2. 极低成本读路径优化：在我们的检索拼接层立刻可吸收 BRIDGE 的「BM25(笔记+原文) + Cosine RRF 融合」与「按时间戳升序渲染」，用极低成本显著改善知识更新题；
3. 直接补强后续 Benchmark 系列：将 RA+ / RA- / PI-S / PI-P / DM 五类“不提规则测执行”的行为测试引入联接 Agent 评测集。 ^txt_0092
