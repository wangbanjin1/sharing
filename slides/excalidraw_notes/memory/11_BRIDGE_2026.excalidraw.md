核心定位与关键发现（问题 · 极简三原语 · 五类行为测试 · 架构分化结论） ^txt_0027

直击核心追问：复杂记忆原语在标准问答基准上到底值不值成本？记忆架构真正分出高下的地方在哪里？ ^txt_0028

1. 解决什么问题 ^txt_0030

1. 现有记忆系统不断堆叠抽取、冲突覆写、反思、知识图谱等重型原语，但缺乏极简强基线检验这些高成本模块是否真有净收益；
2. 现有基准（LoCoMo / LongMemEval）只测“能不能答出关于过去的问题（召回）”，却不测“新任务不提旧规则时，Agent 能否自觉应用记住的规则与模式（执行）”。 ^txt_0031

2. BRIDGE 极简数据结构（零图谱 · 零覆写 · 双存原文） ^txt_0033

3. 核心实证：没有单一记忆架构能通吃所有行为测试 ^txt_0036

• 显式规则应用（RA+ / RA-）：原子事实抽取器（如 LangMem）胜出，因为独立短规则更容易被下游模型注意到并严格执行；
• 隐式模式归纳（PI-S / PI-P）：块摘要/原文记忆（BRIDGE）胜出，因为原子事实抽取在压缩时丢掉了示范代码或流程的原始形态；
• 关键归因：块摘要在规则题上并非“没检索到”，而是“检索到了但下游模型没照做”——只需在呈现时突出规则即可大幅缩小差距。 ^txt_0037

4. 评测方法论突破（生成期约束裁判 + 跨厂商防偏见） ^txt_0039

• 对抗测试不比对参考答案文本，而是针对每条约束逐项判为 applied / violated / n/a；
• 裁判模型强制选用与数据生成器、被测 Reader 不同厂商的模型，消除同家族自偏好偏差。 ^txt_0040

BRIDGE 极简记忆 · 全生命周期流水线（生成 → 更新 → 检索 ｜ 遗忘 · 删除） ^txt_0042

全程零覆写、零删改，靠「原文+笔记双存」「双通道 RRF」「两级渲染+时间升序」取胜 ^txt_0043

对联接 Agent 架构选型与评测体系的直接落地启发 ^txt_0091

1. 印证「双轨混合记忆」必要性：显式偏好与禁用约束必须抽为原子结构化槽位（如语义记忆表，防“召回了却没执行”），而历史单据与多轮交互过程需保留原文槽位 + 时间升序
   （防细节与模式丢失）；
2. 极低成本读路径优化：在我们的检索拼接层立刻可吸收 BRIDGE 的「BM25(笔记+原文) + Cosine RRF 融合」与「按时间戳升序渲染」，用极低成本显著改善知识更新题；
3. 直接补强后续 Benchmark 系列：将 RA+ / RA- / PI-S / PI-P / DM 五类“不提规则测执行”的行为测试引入联接 Agent 评测集。 ^txt_0092
