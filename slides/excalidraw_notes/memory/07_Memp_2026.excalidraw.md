对联接 Agent 程序记忆体系的设计启发（对应总表） ^txt_0095

1. 直接复用「命中次数 + 采用胜率」闭环淘汰机制：在联接 Agent 程序记忆中维护每条澄清/保障策略的历史采用胜率状态，持续淘汰失效或产生负面追问的旧策略；
2. 借鉴「核心要素逐项匹配」检索思路：按业务类型、缺失槽位、冲突特征等正交要素分别匹配而非整句模糊匹配，提高澄清策略命中精度；
3. 强弱模型迁移落地：离线可用大模型复盘高质量澄清与保障经验入库，在线挂载给低延迟小模型执行快路径/慢路径意图提取。 ^txt_0096
