1. 解决什么问题 ^txt_0025

现有记忆框架通常把长期记忆（LTM）与短期工作记忆（STM）拆成割裂组件，依赖手工触发规则或外置静态控制器，既无法根据任务需要动态裁剪干扰上下文，也无法端到端协同优化「
存什么、留什么、检什么」。 ^txt_0026

2. 统一 6 工具动作空间（纳入主模型策略） ^txt_0028

• 长期记忆（LTM）三工具：ADD（新增持久化条目）、UPDATE（按 memory_id 修改旧条目）、DELETE（移除陈旧条目防膨胀）；
• 短期上下文（STM）三工具：RETRIEVE（从 LTM 召回 Top-k 注入当前上下文）、SUMMARY（压缩指定历史片段保核心降 token）、FILTER（移除语义相似度超过过滤阈值的无关干
  扰消息）。 ^txt_0029

3. 三阶段渐进 RL 训练课程（解耦并阻断捷径泄漏） ^txt_0031

• Stage 1（LTM 构建）：在日常交互上下文中自主识别有价值信息写入 LTM；
• Stage 2（抗干扰 STM 控噪）：【强制清空短期上下文、保留 LTM】，合成注入拟真无关干扰句（DistractorGen），逼迫模型学会调用 FILTER / SUMMARY 控噪防溢出；
• Stage 3（联合检索解题）：收到正式任务查询，协同检索 LTM、管理 STM 并输出最终答案。 ^txt_0032

4. Step-wise GRPO 与四项复合奖励 ^txt_0034

长短期记忆统一管理 · 全生命周期流水线（生成 → 更新 → 检索 ｜ 遗忘 · 删除） ^txt_0037

单一 RL 策略在对话全程按需调用 6 工具，实现 LTM 持久化与 STM 动态控噪闭环 ^txt_0038

1. 生成（LTM ADD） ^txt_0040

交互中自主触发写入 ^txt_0041

算法流程 ^txt_0043

智能体在观测当前上下文、长期记忆库与任务目标后，自主决定是否调
用 ADD 工具将高复用价值知识写入长期库（受存储质量奖励正向激励）
。 ^txt_0044

阈值与时机 ^txt_0046

• 无固定启发式阈值，由 RL 策略动态决策；
• 时机：对话任意步骤按需调用。 ^txt_0047

2. 更新（LTM UPDATE + STM SUMMARY） ^txt_0049

长期改写与短期压缩协同 ^txt_0050

算法流程 ^txt_0052

1. 长期层：调用 UPDATE 工具按 memory_id 修改已有条目，消除过时冲突；

2. 短期层：在上下文接近上限或出现冗余段落时，主动调用 SUMMARY 将
   指定历史片段压缩为精炼摘要。 ^txt_0053

阈值与时机 ^txt_0055

• 预防性压缩受上下文奖励正向激励，溢出受重罚；
• 时机：上下文增长或状态变化时自主触发。 ^txt_0056

3. 检索（STM RETRIEVE） ^txt_0058

按需把 LTM 拉入当前上下文 ^txt_0059

检索与重排流程 ^txt_0061

智能体在需要历史知识支撑推理时，主动调用 RETRIEVE 工具，从持久化库
按语义相似度召回 Top-k 条目注入当前工作上下文（由 LLM 评估召回相关
性反馈进记忆奖励）。 ^txt_0062

检索时机 ^txt_0064

Stage 3 解题或任意缺信息推理步按需触发。 ^txt_0065

4. 遗忘（STM FILTER 控噪） ^txt_0067

主动剔除干扰与冗余上下文 ^txt_0068

机制说明 ^txt_0070

调用 FILTER 工具移除当前上下文中与过滤准则语
义相似度超过设定阈值的无关/干扰消息，防止无
关闲聊和干扰句污染推理并节省 token。 ^txt_0071

5. 删除（LTM DELETE） ^txt_0073

主动清理陈旧长期条目 ^txt_0074

机制说明 ^txt_0076

智能体自主调用 DELETE 工具移除长期库中过
时或冗余的条目，防止库容无界膨胀并获得维
护奖励。 ^txt_0077

原论文实证特点与课程通用性 ^txt_0083

• 多基准一致提升：在 5 个长程基准及多个主流基座模型（如 Qwen2.5-7B、Qwen3-4B）上，AgeMem 相比静态/分离记忆基线同时提升了任务准确率、长期记忆存储质量与上下
  文 token 使用效率；
• 课程解耦优势：Stage 1→2 之间强制重置 STM 上下文，从物理上杜绝模型靠残余短期上下文偷懒答题，逼迫模型真正学会正确写入与检索 LTM；Stage 2 干扰项可自动合成，
  不依赖额外人工标注。 ^txt_0084

对联接 Agent 记忆与评测体系的设计启发 ^txt_0086

1. 与我们的评测隔离协议高度共振：Stage 1 建库 → 重置上下文 → Stage 2 抗干扰 → Stage 3 跨会话解题，正是检验「是否真用记忆而非靠上下文捷径」的标准范式；
2. 引入主动 STM 控噪工具（FILTER / SUMMARY）：在多轮慢路径澄清或长单据排障中，当用户插话闲聊或改口时，主动过滤无效轮次可显著减少槽位干扰；
3. 复合奖励结构参考：评测记忆不能只看最终答题分，需同步度量长期记忆存储质量、去陈旧维护行为与上下文压缩保真度。 ^txt_0087
