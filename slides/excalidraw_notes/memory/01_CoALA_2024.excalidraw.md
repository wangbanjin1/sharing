1. 情景记忆（Episodic）：问题 · 输入 · 输出 · 存储 ^txt_0030

• 解决问题：跨会话保留历史交互辅助指代理解；为规划提供相似轨迹先验；作反思归纳语义的原始来源。
• 输入与存储：工作记忆历史对话 + 外部动作与环境反馈序列 ｜ 存储：结构化文本。
• 标准输出：时间（决策顺序/时间戳，可含最近访问时间）、起因（初始指令/感知）、经过（对话、推理与工具反馈序列）、结果（外部动作/任务终态，附重要度评分，无有效期字段）。
 ^txt_0031

2. 语义记忆（Semantic）：问题 · 输入 · 输出 · 存储 ^txt_0033

• 解决问题：跨会话保存外部领域客观知识与归纳的用户事实规律；避免每次从冗长对话重新归纳。
• 输入与存储：工作记忆近期经历或情景检索事件 + 外部只读文档库 ｜ 存储：非结构化文本 + 向量数据库。
• 标准输出：全局共享作用域（未按单用户多场景/时段隔离）；外部只读文档片段或反思事实三元组（附重要度评分）；无生效/失效时间戳与冲突状态字段，仅保留来源情景地址。 ^txt_0034

3. 程序记忆（Procedural）：问题 · 输入 · 输出 · 存储 ^txt_0036

• 解决问题：沉淀可跨会话调用的标准执行流程与可执行技能代码，减少同类任务从零试错开销。
• 输入与存储：当前任务目标、环境报错反馈与候选技能代码 + 预置模型权重与主控循环源码 ｜ 存储：模型参数权重 + 代码文件 + 向量数据库。
• 标准输出：触发条件（技能函数自然语言 docstring 向量）、策略动作（模型权重 + 可执行源码 {skill_name, executable_code} 与主循环）、结果出处（仅存沙箱验证通过版本）。 ^txt_0037

文中所引代表系统的参考阈值与案例（对应表格备注行） ^txt_0180

• Generative Agents：情景事件由大模型打 1~10 分重要度，检索按近度衰减（0.995^Δt）+ 重要度 + 余弦相似度等权相加；未反思事件重要度累加 > 150 分时触发高层反思生
  成语义断言（如“用户喜欢滑雪”）；
• Reflexion：单次任务失败即触发语言反思并写回记忆；
• Voyager：外部沙箱验证通过的 JavaScript 技能函数写入技能库，动作规划前按余弦相似度召回 K = 5 个技能。 ^txt_0181

对比联接 Agent 记忆体系的设计补强（对应总表与补充说明） ^txt_0183

1. 补齐全生命周期治理：CoALA 仅覆盖追加写入，联接 Agent 需补齐语义记忆的冲突状态机（候选 / 生效 / 强化 / 已失效）与生效/失效时间戳；
2. 补齐单用户多维度作用域：将语义记忆从全局共享细化为「特定用户 + 业务场景 / 周期时段条件」，避免跨场景偏好串扰；
3. 补齐程序记忆的对话澄清形态：除可执行代码技能外，将多轮澄清提问策略与保障排障准则沉淀为带禁用边界与原话出处的三段式经验条目。 ^txt_0184
